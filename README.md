# Bloody B975 RGB Controller

برنامه ویندوزی برای ترکیب هم‌زمان این دو افکت روی کیبورد Bloody B975:

- Breathing سراسری با رنگ، سرعت و حداقل روشنایی قابل تنظیم
- بارگذاری فایل‌های `.ckPannel` مثل `My_Custom.ckPannel` برای رنگ جداگانه هر کلید
- ویرایشگر تصویری چیدمان B975 برای رنگ ثابت یا گرادیان زاویه‌دار روی کلیدها
- Flash/Fade سفید یا رنگ دلخواه روی همان کلیدی که فشرده می‌شود
- Meteor ردیفی با پشتیبانی از فایل‌های `ButtonType=1` با پسوند `.ckButton`

پروتکل روی نمونه واقعی `VID 09DA / PID FA10` و رابط
`MI_02 / COL04` آزمایش شده است. نگاشت ردیفی LEDها و ارسال زنده فریم نیز روی
همین مدل تأیید شده‌اند.

## اجرای پروژه در Visual Studio

1. `B975RgbApp.sln` را با Visual Studio 2022 باز کن.
2. اگر خواست، workload مربوط به `.NET Desktop Development` و SDK دات‌نت 8 را نصب کن.
3. KeyDominator را از System Tray کامل ببند.
4. پروژه را با `F5` اجرا کن.
5. تنظیمات را انتخاب کن و دکمه «شروع» را بزن.

برای استفاده از رنگ‌بندی آماده، روبه‌روی «رنگ‌بندی جداگانه کلیدها» دکمه
«بارگذاری» را بزن و فایل `.ckPannel` را انتخاب کن. رنگ‌های فایل یک‌بار خوانده و
داخل تنظیمات برنامه ذخیره می‌شوند؛ بعداً لازم نیست فایل در همان مسیر باقی بماند.

برای ساخت طرح داخل خود برنامه، دکمه «طراحی» را بزن. در صفحه ویرایشگر:

- با کلیک یک کلید و با نگه‌داشتن `Ctrl` چند کلید را انتخاب کن.
- برای انتخاب یک ناحیه روی صفحه کیبورد کادر بکش.
- رنگ ثابت دلخواه را روی انتخاب اعمال کن.
- گرادیان دو یا سه‌رنگ بساز و زاویه را از `-180` تا `180` درجه تعیین کن؛ زاویه
  `45` درجه یک طرح مورب می‌سازد.
- `Ctrl+A` همه کلیدها و `Esc` انتخاب را پاک می‌کند.
- Undo، Redo و بازنشانی به طرح ابتدای ورود به ویرایشگر در دسترس است.

اگر هیچ کلیدی انتخاب نشده باشد، رنگ ثابت یا گرادیان روی تمام ۱۰۴ کلید اصلی
اعمال می‌شود. ۱۲ اسلات نور اضافه B975 که روی نمای فیزیکی کلید ندارند بدون تغییر
حفظ می‌شوند. پس از «اعمال و بستن»، دکمه «شروع» را بزن تا طرح روی کیبورد اجرا شود.

برای Meteor، نوع افکت واکنشی را روی «Meteor ردیفی» بگذار. تنظیم پیش‌فرض از
`Click_meteor.ckButton` گرفته شده است. با دکمه «بارگذاری ckButton» نیز می‌توانی
رنگ‌ها و Speed یک فایل Meteor دیگر را وارد کنی. این افکت از کلید زده‌شده در
امتداد همان ردیف حرکت می‌کند و بعد به Breathing پس‌زمینه برمی‌گردد.

برنامه به دسترسی Administrator احتیاج ندارد، مگر اینکه Policy یا نرم‌افزار دیگری
دسترسی به رابط HID را محدود کرده باشد.

## ساخت فایل EXE

در PowerShell داخل پوشه پروژه:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\build-release.ps1
```

خروجی framework-dependent در مسیر زیر ساخته می‌شود:

```text
publish\win-x64\B975RgbApp.exe
```

اگر می‌خواهی روی سیستمی که .NET Desktop Runtime 8 ندارد نیز اجرا شود:

```powershell
.\build-release.ps1 -SelfContained
```

## رفتار برنامه

- تنظیمات در `%LocalAppData%\B975RgbApp\settings.json` ذخیره می‌شوند.
- گزینه اجرای همراه ویندوز فقط مقدار کاربر جاری را در Run Registry تنظیم می‌کند.
- در حالت Close to Tray، ضربدر پنجره برنامه را متوقف نمی‌کند؛ برای خروج کامل از
  منوی کنار ساعت «خروج کامل» را بزن.
- کلید Fn معمولاً رویداد استاندارد ویندوز تولید نمی‌کند و ممکن است افکت واکنشی نداشته باشد.
- هنگام توقف، نور روی رنگ کامل پس‌زمینه یا رنگ‌بندی کامل فایل ckPannel ثابت می‌ماند.

## وضعیت نسخه فعلی

این نسخه فایل ckPannel و ویرایشگر تصویری را برای رنگ پس‌زمینه و فایل ckButton
نوع 1 را برای پارامترهای Meteor پشتیبانی می‌کند. فایل `.ckAnimation` هنوز
مستقیماً پخش نمی‌شود. منطق تأییدشده Flash/Fade حفظ شده و Ripple هنوز اضافه نشده است.
