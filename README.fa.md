# کنترل RGB کیبورد Bloody B975

**فارسی** | [English](README.md)

یک برنامه سبک ویندوزی برای کنترل نورپردازی RGB کیبورد Bloody B975 است. برنامه می‌تواند Breathing پس‌زمینه، رنگ پیش‌فرض جداگانه برای هر کلید و چند افکت واکنشی را هم‌زمان اجرا کند و برای ادامه کار به بازبودن KeyDominator احتیاج ندارد.

> این پروژه مستقل و غیررسمی است و ارتباطی با Bloody/A4Tech ندارد.

## قابلیت‌های اصلی

- پس‌زمینه Breathing با یک رنگ ثابت یا رنگ مجزای هر کلید
- بارگذاری پروفایل‌های رنگ Bloody با پسوند `.ckPannel`
- ویرایشگر تصویری مطابق چیدمان فیزیکی B975
- انتخاب تکی کلیدها، چندانتخاب با `Ctrl` و انتخاب کادری با ماوس
- اعمال رنگ ثابت یا گرادیان زاویه‌دار با ۲ تا ۸ رنگ
- Undo، Redo، بازنشانی، انتخاب همه و لغو انتخاب
- افکت واکنشی Flash/Fade چندرنگ
- افکت Meteor ردیفی با پشتیبانی از پروفایل `.ckButton`
- افکت انفجار شعاعی چندرنگ در تمام جهت‌های فیزیکی کیبورد
- هم‌پوشانی مستقل افکت‌ها؛ زدن کلید جدید افکت قبلی را قطع نمی‌کند
- تغییر فوری زبان بین فارسی و انگلیسی؛ زبان پیش‌فرض فارسی است
- اجرای همراه ویندوز، شروع خودکار افکت و ادامه کار در System Tray

پروتکل HID روی یک نمونه واقعی Bloody B975 با مشخصات زیر آزمایش شده است:

```text
VID: 09DA
PID: FA10
Interface: MI_02 / COL04
```

نگاشت ردیف‌های LED و ارسال پیوسته فریم‌های RGB نیز روی همین دستگاه تأیید شده‌اند.

## پیش‌نیازها

- ویندوز ۱۰ یا ۱۱
- کیبورد Bloody B975
- Visual Studio 2022 با workload مربوط به **.NET Desktop Development** برای Build سورس
- نسخه ۸ دات‌نت SDK برای Build
- نسخه ۸ دات‌نت Desktop Runtime برای خروجی framework-dependent

برنامه معمولاً به دسترسی Administrator احتیاج ندارد؛ مگر اینکه Policy ویندوز یا برنامه دیگری دسترسی به رابط HID کیبورد را محدود کرده باشد.

## اجرای پروژه در Visual Studio

1. فایل `B975RgbApp.sln` را با Visual Studio 2022 باز کن.
2. اگر Visual Studio درخواست کرد، **.NET Desktop Development** و دات‌نت ۸ SDK را نصب کن.
3. KeyDominator را از System Tray و Task Manager کامل ببند.
4. با `F5` برنامه را اجرا کن.
5. رنگ پس‌زمینه و افکت واکنشی را تنظیم کن و دکمه **شروع** را بزن.

زبان بدون نیاز به ری‌استارت تغییر می‌کند و برای اجرای بعدی ذخیره می‌شود. صفحه اصلی، ویرایشگر کیبورد، پیام‌های وضعیت، منوی کنار ساعت، عنوان پنجره‌های انتخاب فایل و خطاهای برنامه از زبان انتخاب‌شده پیروی می‌کنند.

## نور پس‌زمینه

پس‌زمینه را می‌توان به دو شکل تنظیم کرد.

### پس‌زمینه یکپارچه

یک رنگ ثابت انتخاب کن. افکت Breathing روشنایی همین رنگ را بین حداقل روشنایی تنظیم‌شده و شدت کامل تغییر می‌دهد.

### رنگ پیش‌فرض جداگانه برای هر کلید

می‌توانی یک فایل `.ckPannel` وارد کنی یا طرح را داخل خود برنامه بسازی.

برای واردکردن پروفایل:

1. روبه‌روی **رنگ‌بندی جداگانه کلیدها** دکمه **بارگذاری** را بزن.
2. فایل `.ckPannel` را انتخاب کن.

رنگ‌ها داخل تنظیمات برنامه کپی می‌شوند؛ بنابراین بعد از بارگذاری لازم نیست فایل اصلی در همان مسیر باقی بماند.

## ویرایشگر تصویری کیبورد

روبه‌روی **رنگ‌بندی جداگانه کلیدها** دکمه **طراحی** را بزن.

روش‌های انتخاب کلید:

- برای انتخاب یک کلید روی آن کلیک کن.
- برای چندانتخاب، هنگام کلیک `Ctrl` را نگه دار.
- برای انتخاب یک ناحیه روی کیبورد کادر بکش.
- `Ctrl+A` همه کلیدهای فیزیکی را انتخاب می‌کند.
- `Esc` انتخاب را پاک می‌کند.

ابزارهای رنگ:

- یک رنگ ثابت روی کلیدهای انتخاب‌شده اعمال کن.
- گرادیانی با ۲ تا ۸ رنگ مستقل بساز.
- زاویه را بین `-180°` تا `180°` تعیین کن.
- برای تنظیم سریع از زاویه‌های `0°`، `45°`، `90°` و `-45°` استفاده کن.
- در صورت نیاز Undo، Redo یا بازنشانی را بزن.

اگر هیچ کلیدی انتخاب نشده باشد، رنگ ثابت یا گرادیان روی تمام ۱۰۴ کلید فیزیکی اعمال می‌شود. B975 دوازده اسلات نوری اضافه نیز دارد که موقعیت کلید قابل‌نمایش ندارند؛ ویرایشگر این ۱۲ اسلات را بدون تغییر نگه می‌دارد.

در پایان **اعمال و بستن** را بزن و سپس در صفحه اصلی دکمه **شروع** را انتخاب کن تا طرح روی کیبورد ارسال شود.

## افکت‌های واکنشی

### Flash / Fade

کلید فشرده‌شده هنگام محوشدن بین ۸ رنگ تنظیم‌شده افکت حرکت می‌کند و در نهایت به Breathing پس‌زمینه برمی‌گردد. هرکدام از این هشت رنگ از صفحه اصلی قابل تغییر است.

### Meteor ردیفی

Meteor از کلید فشرده‌شده شروع می‌شود و در امتداد همان ردیف حرکت می‌کند. تنظیمات پیش‌فرض را می‌توان با یک فایل Bloody از نوع `.ckButton` که `ButtonType=1` دارد جایگزین کرد.

برای واردکردن Meteor جدید:

1. نوع افکت را روی **Meteor ردیفی** بگذار.
2. دکمه **بارگذاری ckButton** را بزن.
3. فایل `.ckButton` را انتخاب کن.

برنامه رنگ‌های `ButtonDownColor` و مقدار Speed فایل را وارد می‌کند.

### انفجار شعاعی

افکت انفجار شعاعی مرکز فیزیکی کلید فشرده‌شده را مبدأ قرار می‌دهد. یک حلقه چندرنگ در همه جهت‌ها روی کیبورد پخش می‌شود و به‌تدریج داخل رنگ پس‌زمینه محو می‌شود. هسته سفید اجباری نسخه‌های اولیه نیز حذف شده است.

هر بار فشردن کلید یک افکت مستقل می‌سازد. هنگام تایپ سریع یا فشردن چندباره یک کلید، افکت‌ها روی هم اجرا می‌شوند و هر موج تا پایان زمان خودش ادامه پیدا می‌کند.

## ساخت فایل EXE

داخل پوشه اصلی پروژه PowerShell را باز کن:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\build-release.ps1
```

خروجی framework-dependent در مسیر زیر ساخته می‌شود:

```text
publish\win-x64\B975RgbApp.exe
```

برای ساخت خروجی‌ای که روی سیستم بدون دات‌نت Desktop Runtime 8 هم اجرا شود:

```powershell
.\build-release.ps1 -SelfContained
```

## تنظیمات و رفتار برنامه

- تنظیمات در `%LocalAppData%\B975RgbApp\settings.json` ذخیره می‌شوند.
- رنگ‌های واردشده از `.ckPannel` و تنظیمات Meteor فایل `.ckButton` داخل همین فایل تنظیمات ذخیره می‌شوند.
- بستن پنجره می‌تواند برنامه را در System Tray فعال نگه دارد.
- برای بستن کامل از منوی کنار ساعت گزینه **خروج کامل** را بزن.
- با توقف افکت، کیبورد روی رنگ کامل پس‌زمینه باقی می‌ماند و خاموش نمی‌شود.
- Hook سراسری کیبورد فقط هنگام فعال‌بودن نورپردازی اجرا می‌شود. برنامه صرفاً رویداد فشردن کلید را به موقعیت LED تبدیل می‌کند؛ متن تایپ‌شده را ذخیره یا از طریق شبکه ارسال نمی‌کند.
- برنامه در وضعیت فعلی Telemetry و حساب آنلاین ندارد.

## رفع خطاهای رایج

### رابط نورپردازی B975 پیدا نشد

- مطمئن شو کیبورد مستقیم از طریق USB متصل است.
- KeyDominator را از System Tray و Task Manager کامل ببند.
- کیبورد را جدا و دوباره وصل کن و برنامه را مجدداً اجرا کن.
- اگر برنامه RGB دیگری از دستگاه استفاده می‌کند، قبل از زدن **شروع** آن را ببند.

### برنامه از قبل در حال اجراست

System Tray ویندوز را بررسی کن. در هر لحظه فقط یک نمونه از برنامه اجرا می‌شود.

### یک کلید افکت واکنشی ندارد

بعضی کلیدهای سخت‌افزاری، مخصوصاً `Fn`، رویداد استاندارد ویندوز تولید نمی‌کنند؛ بنابراین ممکن است افکت نرم‌افزاری را فعال نکنند.

### بازنشانی کامل تنظیمات

برنامه را کامل ببند و فایل زیر را حذف کن:

```text
%LocalAppData%\B975RgbApp\settings.json
```

اجرای بعدی فایل تنظیمات را دوباره می‌سازد و زبان پیش‌فرض فارسی خواهد بود.

## محدودیت‌های فعلی

- فقط مدل و رابط HID ذکرشده برای Bloody B975 به‌صورت فیزیکی آزمایش شده است.
- پخش مستقیم فایل `.ckAnimation` پیاده‌سازی نشده است.
- واردکردن `.ckButton` در حال حاضر مخصوص Meteor با `ButtonType=1` است.
- موقعیت فیزیکی ۱۰۴ کلید قابل‌مشاهده تعریف شده است؛ ۱۲ اسلات LED باقی‌مانده حفظ می‌شوند ولی داخل ویرایشگر نمایش داده نمی‌شوند.
- نسخه‌های Firmware که HID Collection متفاوتی دارند ممکن است به تغییر رابط دستگاه احتیاج داشته باشند.
